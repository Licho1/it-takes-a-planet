# It Takes a Planet

Read [README.md](README.md) first. It holds the motivation and scope.

## Status

Early stage. Tech stack, data model and UI are not decided. Do not assume them. Discuss larger decisions with the user before building.

## Rules for content

- Every fact (company, place, material, process) needs a source.
- If we do not know, we estimate. Every estimate is marked as an estimate, in the data and in the UI. Never present a guess as a fact.
- Images: only images whose license allows reuse in an open-source project, with attribution (for example Wikimedia Commons). Google Maps and Street View imagery is copyrighted by Google. Do not copy it into the repo. Linking to a place on Google Maps is fine.
- Neutral tone. Describe, do not judge.

## Writing style

Plain, direct, literal English for non-native readers. Short concrete sentences. No metaphors or jargon. This applies to docs, code comments, commit messages and UI texts.

## Working

- The development machine runs Windows.
- Reusable preprocessed data goes to `.cache/`. It is not committed.
